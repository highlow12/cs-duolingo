## 스택의 연산과 활용

push는 top에 값을 넣고, pop은 top의 값을 제거하며 반환합니다. peek은 top을 살펴보기만 하고 제거하지 않는 연산입니다. 연결 리스트 기반 스택에서는 이 연산들을 O(1)에 처리할 수 있습니다. Python 리스트의 append는 가끔 저장 공간을 늘리므로, 여러 번의 연산을 평균내는 분할상환 비용이 O(1)입니다.

괄호 짝 검사, 실행 취소, 깊이 우선 탐색처럼 가장 최근의 상태를 먼저 되돌아가야 하는 문제에서 스택이 자연스럽게 쓰입니다.

Python 리스트에서 `stack[-1]`은 마지막 원소를 제거하지 않고 읽으므로 비어 있지 않은 스택의 peek으로 사용할 수 있습니다.
