# input()으로 값 입력받기

`input()`은 괄호 안의 안내 문구를 먼저 보여 주고 사용자의 입력을 기다립니다.

```python
name = input("이름: ")
print(name)
```

중요한 점은 `input()`이 사용자가 입력한 내용을 항상 문자열(`str`)로 돌려준다는 것입니다. 사용자가 `20`을 입력해도 프로그램이 처음 받는 값은 숫자 20이 아니라 문자열 `"20"`입니다.

따라서 `input()`으로 받은 값은 문자열로 이어 붙이는 등의 연산을 할 수 있습니다. 숫자 계산을 하려면 다음 설명처럼 자료형을 변환해야 합니다.
