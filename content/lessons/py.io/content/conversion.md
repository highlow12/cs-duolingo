# 입력한 문자열을 숫자로 변환하기

숫자로만 이루어진 문자열은 `int()`로 정수로 변환할 수 있습니다.

```python
age = int("20")
print(age + 1)  # 21
```

입력과 변환을 한 줄에 이어 쓰면 `int(input("나이: "))`가 됩니다. `input()`이 먼저 문자열을 받고, 바깥의 `int()`가 그 문자열을 정수로 바꿉니다.

```python
count = int(input("개수: "))
```

정수로 해석할 수 없는 입력을 `int()`에 넣으면 오류가 납니다. 따라서 사용자가 숫자를 입력해야 하는 상황에서만 이 변환을 사용하세요.
