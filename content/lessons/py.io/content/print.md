# print()로 값 출력하기

`print()`는 괄호 안의 값을 화면에 보여 주는 함수입니다. 문자열, 숫자, 변수의 값을 모두 출력할 수 있습니다.

```python
name = "Ada"
print("Hello")
print(name)
```

각 `print()` 호출은 출력한 뒤 줄을 바꿉니다. 여러 값을 쉼표로 넣으면 기본적으로 값 사이에 공백을 넣어 한 줄에 출력합니다.

```python
score = 95
print("score:", score)
# score: 95
```

`print()`는 값을 화면에 보여 주지만, 사용자가 입력한 값을 받지는 않습니다. 입력은 다음에 배울 `input()`이 담당합니다.
