## 비교 연산자 연습

비교 연산자는 두 값을 비교한 결과를 `True` 또는 `False`로 만듭니다.

| 연산자 | 의미                                |
| ------ | ----------------------------------- |
| `>=`   | 왼쪽 값이 오른쪽 값보다 크거나 같다 |
| `==`   | 두 값이 같다                        |
| `<`    | 왼쪽 값이 오른쪽 값보다 작다        |

조건문은 이 결과를 사용해 실행 경로를 선택합니다. 먼저 비교 결과를 예상한 뒤, 어떤 블록이 실행되는지 확인해 보세요.
