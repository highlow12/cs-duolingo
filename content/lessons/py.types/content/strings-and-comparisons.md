# 문자열을 이어 붙이고 값을 비교하기

문자열(`str`)은 `+`로 이어 붙일 수 있고, 문자열에 정수를 곱하면 같은 문자열을 여러 번 반복합니다.

```python
greeting = "Hello, " + "Ada"
sound = "ha" * 3
```

`greeting`은 `"Hello, Ada"`가 되고 `sound`는 `"hahaha"`가 됩니다. 문자열과 숫자를 `+`로 바로 더할 수는 없으므로, 연산하려는 값의 자료형을 먼저 확인해야 합니다.

비교 연산자는 두 값을 비교한 결과를 불리언(`bool`)으로 만듭니다.

| 연산자     | 뜻                       |
| ---------- | ------------------------ |
| `==`       | 같다                     |
| `!=`       | 다르다                   |
| `<`, `>`   | 작다, 크다               |
| `<=`, `>=` | 작거나 같다, 크거나 같다 |

```python
print(3 < 5)       # True
print("a" == "b") # False
```

`=`는 변수에 값을 대입할 때 사용하고, `==`는 두 값이 같은지 비교할 때 사용합니다. 비교 결과인 `True` 또는 `False`는 다음 레슨의 조건문에서 실행할 경로를 고르는 데 사용합니다.
