# 숫자와 산술 연산

`int`는 소수점이 없는 수이고 `float`는 소수점이 있는 수입니다. 두 자료형의 값은 산술 연산에 사용할 수 있습니다.

| 연산자 | 뜻             | 예              |
| ------ | -------------- | --------------- |
| `+`    | 더하기         | `2 + 3`은 `5`   |
| `-`    | 빼기           | `5 - 2`는 `3`   |
| `*`    | 곱하기         | `2 * 3`은 `6`   |
| `/`    | 나누기         | `7 / 2`는 `3.5` |
| `//`   | 몫을 내림한 값 | `7 // 2`는 `3`  |
| `%`    | 나머지         | `7 % 2`는 `1`   |
| `**`   | 거듭제곱       | `2 ** 3`은 `8`  |

`/`는 나눈 결과를 계산하고, `//`는 몫만 남깁니다. 양수에서는 `//`의 결과가 소수점을 버린 것처럼 보입니다. `%`는 나누고 남은 값을 구할 때 사용합니다. `**`의 오른쪽 값은 몇 번 곱할지를 나타냅니다.

연산 결과의 자료형도 생각해 보세요. 예를 들어 `7 / 2`의 결과는 `3.5`인 `float`입니다. 괄호를 사용하면 먼저 계산할 부분을 분명하게 지정할 수 있습니다.
