# Design agent skills

Project-scoped design skills live in `.agents/skills/` and are generated by `scripts/install-design-skills.sh`.

Installed sources:

- `podo/design-agent-skills` — design skill catalogue
- `anthropics/claude-code` — canonical `frontend-design`
- `nmhjklnm/frontend-skills` — frontend/UI skill collection including `calm-ui`; its colliding frontend design variant is retained as `frontend-design-nmh`
- `rikre/design-skills` — visual style/design skill collection
- `richtabor/agent-skills` — `motion-design`
- `TerminalSkills/skills` — `design-md`

Explicitly excluded:

- Microsoft `frontend-design-review`

The install currently resolves to **236 project skills**. Re-run the installer when intentionally updating upstream skills, then review and commit the resulting diff.
